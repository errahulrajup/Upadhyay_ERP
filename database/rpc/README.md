# RPC Functions

Critical workflows must be implemented as transactional database functions.

First vertical-slice RPCs:

- `inv.approve_grn`
- `mfg.create_batch`
- `mfg.start_batch`
- `mfg.complete_batch`
- `qa.release_batch_qc`
- `fin.confirm_dispatch`
- `fin.create_invoice_from_dispatch`
- `fin.post_payment`
