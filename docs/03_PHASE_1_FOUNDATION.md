# Phase 1 Foundation

## Goal

Create a clean, buildable repo baseline for `Upadhyay_ERP`.

## Created

- npm workspace root
- React/Vite web app in `apps/web`
- strict TypeScript base config
- app shell for Phase 1
- foundation smoke test
- database migration skeleton
- migration checker tool
- env example

## Gate Commands

From repo root:

```powershell
npm install
npm run build
npm test
npm run db:check
```

## Exit Criteria

- install completes
- build passes
- tests pass
- migration checker passes
- no dependency on old `D:\SVRERP` runtime code
